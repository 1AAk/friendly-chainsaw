## Параллельный трек: UI Kit (вместе с обучением)
**Идея:** каждый новый экран собираем **только** из компонентов UI Kit. Это сразу закрепляет знания на практике.

**Правила UI Kit:**
- Один компонент = один файл/папка + краткий usage note.
- У каждого компонента есть состояния (default/hover/focus/disabled).
- Демо компонентов — в Library.

**Список компонентов UI Kit (можно менять):**

**Мини-версия UI Kit по этапам:**
- v0.1: Button, Input, Card, Section.
