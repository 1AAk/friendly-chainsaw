# Дорожная карта проекта - обучение UI/UX

## 1. Видение
- Обучаться UI/UX через практику и визуальные примеры.
- Собрать библиотеку shared компонентов.
- Сформировать портфолио паттернов интерфейса.

## 2. Текущее состояние
- Базовый скелет проекта (Vite + React + Tailwind + Docker).
- Стартовый UI-экран и структура.

## 3. Этапы и цели
| Этап | Цель | Статус |
| --- | --- | --- |
| E1. Design Tokens | Цвета, типографика, отступы, радиусы | [ ] |
| E2. Shared Components | Button, Input, Card, Section | [ ] |
| E3. UI Examples | 2-3 экрана с разными паттернами | [ ] |
| E4. Interactions | Анимации и полировка состояний | [ ] |
| E5. Accessibility & Responsive | Контраст, focus, брейкпоинты | [ ] |
| E6. Documentation | Заметки по компонентам и гайд | [ ] |
| E7. Localization | RU/EN i18n базовый слой | [ ] |

## 4. Подробный план

### E1. Design Tokens
- Задать палитру, шкалу типографики, систему отступов.
- Закодировать токены в `tailwind.config.cjs`.

### E2. Shared Components
- Собрать базовые компоненты с вариантами и размерами.
- Описать правила именования и использования.

### E3. UI Examples
- Сделать лендинг, карточную сетку и форму.
- Примеры должны использовать shared компоненты.

### E4. Interactions
- Добавить входные анимации и hover-состояния.
- Двигать осторожно, не мешая восприятию.

### E5. Accessibility & Responsive
- Видимые focus-состояния и достаточный контраст.
- Проверка на mobile и desktop.

### E6. Documentation
- Обновить `README.md` с заметками по использованию.
- Зафиксировать решения в `.memory_bank/`.

### E7. Localization
- Добавить i18n-слой (i18next/react-i18next или аналог).
- Подготовить RU/EN локали и подключение.

## 5. Следующие шаги
1. Определить дизайн-токены (E1).
2. Собрать shared компоненты (E2).
3. Сделать первый UI пример (E3).
4. Запланировать локализацию RU/EN (E7).

## Версии зависимостей
- Можно использовать context7 для проверки актуальных версий библиотек и необходимых зависимостей перед обновлениями.
