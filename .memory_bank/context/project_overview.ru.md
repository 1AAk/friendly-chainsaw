# Обзор проекта

- **Цель**: обучение UI/UX через практические визуальные примеры и сборку собственной библиотеки shared компонентов.
- **Формат**: React + Vite + Tailwind приложение с каталогом компонентов и экранами-примерами.
- **Ключевые результаты**:
  - дизайн-токены (цвета, типографика, отступы, радиусы) в Tailwind.
  - базовый набор shared компонентов (Button, Input, Card, Section).
  - галерея UI/UX примеров и паттернов экранов.
  - короткие заметки по использованию компонентов.
  - базовая локализация RU/EN через i18n-слой.
- **Ограничения**:
  - минимум зависимостей.
  - все работает локально и в Docker без сложной инфраструктуры.

Связанные документы: `TECH_STACK.MD`, `PROJECT_ROADMAP.MD`, `CODING_STYLE.MD`.
