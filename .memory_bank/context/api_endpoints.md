# UI Routes and Examples

This project has no backend endpoints. Instead, document **UI routes and demo sections** used for learning and the component library.

## Planned sections
- **Home** (`/`)
  - Project goal and current learning focus.
- **Component Library** (`/library`)
  - Catalog of shared components with variants.
- **Layouts and Screens** (`/examples`)
  - Screen patterns: landing page, card grid, forms.
- **Interaction Lab** (`/interactions`)
  - Micro-animations and state transitions.

If a router is not used yet, build these as switchable sections on a single page.
