# Базовые правила безопасности

- **Секреты**
  - Не коммитить ключи и токены.
  - Переменные Vite должны иметь префикс `VITE_` и считаются публичными.

- **Контент**
  - Использовать только моковые/демо данные.
  - Не встраивать реальные API ключи в UI-примеры.

- **Публикация**
  - Проверять, что `.env` и временные файлы не попадают в git.
  - Следить за актуальностью `.gitignore` и `.dockerignore`.

Если появится бэкенд или внешние API, расширить этот файл конкретными правилами.

## Версии зависимостей
- Можно использовать context7 для проверки актуальных версий библиотек и необходимых зависимостей перед обновлениями.
