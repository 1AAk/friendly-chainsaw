# Project Overview

- **Goal**: learn UI/UX through hands-on visual examples while building a shared component library.
- **Format**: React + Vite + Tailwind app with a component catalog and example screens.
- **Key outcomes**:
  - design tokens (colors, type scale, spacing, radii) in Tailwind.
  - a base set of shared components (Button, Input, Card, Section).
  - a gallery of UI/UX examples and screen patterns.
  - short usage notes for components.
  - basic RU/EN localization via an i18n layer.
- **Constraints**:
  - keep dependencies minimal.
  - everything runs locally and in Docker without complex infra.
