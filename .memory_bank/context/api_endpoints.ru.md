# UI-роуты и примеры

В проекте нет бэкенд-эндпоинтов. Вместо этого описываем **UI-роуты и демо-секции**, которые нужны для обучения и библиотеки компонентов.

## Планируемые секции
- **Главная** (`/`)
  - Цель проекта и текущий фокус обучения.
- **Component Library** (`/library`)
  - Каталог shared компонентов с вариантами.
- **Layouts and Screens** (`/examples`)
  - Паттерны экранов: лендинг, карточная сетка, формы.
- **Interaction Lab** (`/interactions`)
  - Микро-анимации и переходы состояний.

Если роутер пока не используется, секции можно сделать переключаемыми на одной странице.

## Версии зависимостей
- Можно использовать context7 для проверки актуальных версий библиотек и необходимых зависимостей перед обновлениями.
