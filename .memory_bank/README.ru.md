# Memory Bank - обзор

Memory Bank - легкий контекст для проекта обучения UI/UX. Помогает быстро найти цели, инфраструктуру и активные задачи без чтения всего репозитория.

## Структура
- `context/` - стабильные факты о проекте (цели, инфраструктура, безопасность, UI-роуты/примеры).
- `current_tasks.md` - текущие приоритеты.
- `tasks/` - карточки задач (`task_<slug>_<hash>.md`) и архив.
- `workflows/` - сценарии работы (bug fix, feature delivery, infra change, dependency update).
- `changelog.md` - краткие заметки по сессиям.

## Как использовать
1. Перед работой: прочитать этот файл, затем `context/*.md` и `current_tasks.md`.
2. Во время работы: следовать соответствующему workflow в `workflows/`.
3. После работы: обновить контекст и добавить заметку в `changelog.md`.

## Правила поддержки
- Держать документы короткими и фактическими; ссылаться на `PROJECT_ROADMAP.MD`, `TECH_STACK.MD`, `CODING_STYLE.MD`.
- Любые изменения стека или инфраструктуры отражать здесь и в основных документах.
- Добавлять workflow для повторяющихся процедур.

Memory Bank помогает сохранять контекст между сессиями.

## Версии зависимостей
- Можно использовать context7 для проверки актуальных версий библиотек и необходимых зависимостей перед обновлениями.
