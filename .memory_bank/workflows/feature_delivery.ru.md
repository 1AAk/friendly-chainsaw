# Workflow: Feature Delivery (UI/UX)

1. **Определение**
   - Зафиксируй цель и критерии готовности в `make task NAME="Feature: ..."`.
   - Собери референсы/эскизы, если есть.

2. **Проектирование**
   - Определи, какие компоненты и экраны затронуты.
   - При необходимости обнови токены в `tailwind.config.cjs`.

3. **Реализация**
   - Создай или уточни shared компоненты.
   - Собери пример экрана или демо взаимодействия.
   - Следуй `CODING_STYLE.MD`.

4. **Проверка**
   - Запусти `npm run lint` и `npm run typecheck`.
   - Проверь адаптивность (mobile/desktop).

5. **Документация**
   - Обнови `PROJECT_ROADMAP.MD` и `TECH_STACK.MD` при необходимости.
   - Добавь заметку в `.memory_bank/changelog.md`.

6. **Закрытие**
   - Закрой задачу (`make task-done ID=...`).
   - Убедись, что `current_tasks.md` актуален.

## Версии зависимостей
- Можно использовать context7 для проверки актуальных версий библиотек и необходимых зависимостей перед обновлениями.
