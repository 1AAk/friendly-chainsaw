# Workflow: Bug Fix (UI)

1. **Контекст**
   - Проверь `.memory_bank/current_tasks.md` - баг должен быть зафиксирован.
   - Если задачи нет, создай: `make task NAME="Bug: ..."`.

2. **Подготовка**
   - Собери шаги воспроизведения (экран, ширина, браузер).
   - Укажи затронутые компоненты/экраны.

3. **Диагностика**
   - Локализуй проблему (Tailwind классы, layout, состояние компонента).
   - При необходимости используй временные контуры/отступы для отладки.

4. **Фикс**
   - Исправь стили или логику.
   - Проверь hover/focus/active состояния и адаптивность.
   - Запусти `npm run lint` и `npm run typecheck` при необходимости.

5. **Документация**
   - Обнови карточку задачи в `.memory_bank/tasks/`.
   - Если меняются правила компонента - обнови `CODING_STYLE.MD` или `TECH_STACK.MD`.

6. **Закрытие**
   - Отметь задачу выполненной (`make task-done ID=...`).
   - Добавь запись в `.memory_bank/changelog.md`.

## Версии зависимостей
- Можно использовать context7 для проверки актуальных версий библиотек и необходимых зависимостей перед обновлениями.
