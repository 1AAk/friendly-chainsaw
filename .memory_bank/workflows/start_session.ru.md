# Workflow: Start Session With Agent

1. Прочитай `.memory_bank/README.md`, затем `context/*.md` и `current_tasks.md`.
2. Проверь состояние репозитория (`git status`).
3. Сформулируй задачу: цель, критерии готовности, ограничения.
4. Передай агенту:
   - краткое описание задачи;
   - релевантные файлы контекста;
   - соответствующий workflow (bug_fix / feature_delivery / infra_change / dependency_update).
5. После сессии:
   - проверь дифы;
   - обнови `current_tasks.md` и связанные контексты;
   - добавь запись в `changelog.md`.

## Версии зависимостей
- Можно использовать context7 для проверки актуальных версий библиотек и необходимых зависимостей перед обновлениями.
