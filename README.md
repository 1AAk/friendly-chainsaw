# UI/UX Starter

A minimal React + Vite + Tailwind starter with ESLint, Prettier, and Docker.

## Quickstart

```bash
pnpm install
npm run dev
```

## Docker (dev with HMR)

```bash
make docker-dev
```

## Docker (production build)

```bash
make docker-build
make docker-run
```

Open http://localhost:5173 for dev, or http://localhost:8080 for prod.

## Localization
- You can use an i18n solution (i18next/react-i18next or equivalent).
- Start with RU/EN locales.

## Dependency versions
- You can use context7 to check the latest versions of libraries and required dependencies before updates.
