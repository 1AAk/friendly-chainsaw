# Стек технологий

## Core
- **TypeScript** - типобезопасная разработка UI.
- **React 18** - функциональные компоненты и hooks.
- **Vite** - быстрый dev сервер и сборка.

## Styling
- **Tailwind CSS** - utility-first стиль для быстрых UI-итераций.
- **PostCSS + Autoprefixer** - обработка CSS.

## Routing
- **React Router** - клиентский роутинг и подгрузка i18n namespaces по маршрутам.

## Tooling
- **pnpm** - менеджер пакетов.
- **ESLint** - проверка качества кода.
- **Prettier** - форматирование.

## Infrastructure
- **Docker + docker compose** - dev и production workflow.
- **Nginx** - раздача production-бандла.

## Локализация
- **i18n (i18next/react-i18next или аналог)** - поддержка RU/EN.

## Optional (позже)
- **Storybook/Styleguide** - визуальная документация компонентов.
- **Playwright** - UI регрессионные тесты.

## Версии зависимостей
- Можно использовать context7 для проверки актуальных версий библиотек и необходимых зависимостей перед обновлениями.
