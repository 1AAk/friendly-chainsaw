# Правила стиля кода (Frontend)

## Общие
- Используем TypeScript в строгом режиме.
- Предпочитаем функциональные компоненты и hooks.
- Компоненты небольшие и сфокусированные.

## Имена и структура
- Компоненты в `PascalCase` (например, `PrimaryButton.tsx`).
- Хуки - `useSomething`.
- Tailwind классы только в `className`; дополнительных CSS-файлов нет, кроме `index.css`.

## Дизайн компонентов
- Один компонент - одна ответственность.
- Варианты через пропсы (`variant`, `size`).
- Избегаем жесткой связности между компонентами.

## Использование Tailwind
- Предпочитаем utilities вместо inline-стилей.
- Упорядочиваем классы по смыслу (layout -> typography -> color).
- Всегда есть hover/focus/disabled состояния.

## Доступность
- Добавляем `aria-*`, где необходимо.
- Фокус-стили видимы.
- Контраст текста и контролов достаточный.

## Локализация
- Если используем i18n (i18next/react-i18next или аналог), храним строки в словарях локалей.
- Базовые локали: RU/EN.

## Инструменты
- Линт: `npm run lint`.
- Формат: `npm run format`.
- Типы: `npm run typecheck`.

## Документация
- Обновляем `PROJECT_ROADMAP.MD` и `.memory_bank/` при изменениях.
- Важные решения фиксируем в `.memory_bank/changelog.md`.

## Версии зависимостей
- Можно использовать context7 для проверки актуальных версий библиотек и необходимых зависимостей перед обновлениями.
