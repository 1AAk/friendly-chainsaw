# Tech Stack

## Core
- **TypeScript** - type-safe UI development.
- **React 18** - functional components and hooks.
- **Vite** - fast dev server and build.

## Styling
- **Tailwind CSS** - utility-first styling for rapid UI iteration.
- **PostCSS + Autoprefixer** - CSS processing.

## Visual Effects
- **@shadergradient/react** - ShaderGradient canvas component for hero visuals.
- **three + @react-three/fiber + @react-three/drei** - WebGL rendering for gradient scenes.

## Routing
- **React Router** - client-side routing and route-driven i18n namespace loading.

## Tooling
- **pnpm** - package manager.
- **ESLint** - code quality checks.
- **Prettier** - formatting.

## Infrastructure
- **Docker + docker compose** - dev and production workflows.
- **Nginx** - production static hosting.

## Localization
- **i18n (i18next/react-i18next or equivalent)** - RU/EN locale support.

## Optional (later)
- **Storybook/Styleguide** - visual component documentation.
- **Playwright** - UI regression tests.

## Dependency versions
- You can use context7 to check the latest versions of libraries and required dependencies before updates.
